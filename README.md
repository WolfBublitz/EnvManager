# EnvManager

A shell-based environment management tool that allows you to easily manage and switch between different development environments. It provides a simple interface for creating, activating, and deleting environments, as well as managing dependencies and configurations.

## Features

- Create and manage multiple environments
- Activate and deactivate environments with ease
- Install and manage dependencies within each environment
- Switch between environments seamlessly
- Keep track of environment configurations and settings
- Integrate with Git for version control of environment configurations

## Installation

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/WolfBublitz/EnvManager/refs/heads/master/src/env.sh) init
```
